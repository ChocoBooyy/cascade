# Cascade

A visual effects and sequencing library for NeoForge 1.21.1. Code-first API for beams,
particle emitters, and choreographed effect timelines.

Cascade is a developer library. On its own it adds nothing to the game.

## Modules

- `engine` - pure Java easing, curves, and the sequencing runtime. No Minecraft dependency.
- `common` - effect model, emitter, registry, and the public builder API.
- `neoforge` - rendering, networking, and the NeoForge entry point.

## Status

Early development. The sequencing core lands first; rendering follows.
